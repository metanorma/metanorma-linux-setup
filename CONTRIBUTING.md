## Welcome!

We're so glad you're thinking about contributing to a Ribose open source project!
If you're unsure or afraid of anything, just ask or submit the issue or pull
request anyways. The worst that can happen is that you'll be politely asked to
change something. We appreciate any sort of contribution, and don't want a
wall of rules to get in the way of that.

Before contributing, we encourage you to read our CONTRIBUTING policy
(you are here), our LICENSE, and our README, all of which should be in this
repository. If you have any questions, or want to read more about our
underlying policies, you can consult the Metanorma Open Source Policy or contact
us at [open.source@ribose.com](mailto:open.source@ribose.com).

## Contributing to the scripts

Edit the `mac` file.
If you added or removed any tools, document your changes in the `README.md`
file.
Follow shell style guidelines by using [ShellCheck].

```sh
# Install shellcheck
brew install shellcheck

# Run shellcheck from the root of the repo
shellcheck mac
```

[ShellCheck]: http://www.shellcheck.net/about.html

## Ribose Contributor License Agreement

Before your first pull request can be merged in any Ribose GitHub
organization, you need to be covered by the Ribose Contributor License
Agreement (CLA). Sign once; one signature covers every Ribose
organization.

- **Individual contributors** — sign the Individual CLA at
  <https://cla.ribose.com/icla>. The `cla/ribose` check on your pull
  request reports the state, and you can also sign from the pull request
  by commenting `@ribose-cla agree` and completing the one-click link
  the App replies with.
- **Corporate contributors** — if your employer has an executed
  Organization CLA, the employer's Point of Contact adds your GitHub
  handle to its Schedule A at
  <https://cla.ribose.com/organizations>, or you can request coverage
  there yourself. No individual signature is then needed.
- **The full guide** — the signing flows and the agreement text are at
  <https://github.com/riboseinc/cla/blob/main/docs/SIGNING.md>.
